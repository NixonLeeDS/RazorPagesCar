**RazorPagesCar**

This was an ASP.NET Core Razor Pages app. It shows how to build a simple car management system with authentication and CRUD functions.

**Features**
- ASP.NET Core Razor Pages
- Entity Framework Core
- Identity authentication and user accounts
- CRUD for cars
- Config with appsettings.json

**Tech Stack**
-.NET Core / ASP.NET Core Razor Pages
- C#
- Entity Framework Core (SQL Server by default)
- ASP.NET Core Identity
- UI: Razor Pages with Bootstrap

Getting Started
**Prerequisites**
- .NET Core 3.1 SDK
- SQL Server LocalDB (installed with Visual Studio) or SQLite
